# Checklist de Subida a KDP

Recorrer interactivamente con el usuario. Marcar cada ítem y señalar los que faltan antes de subir.

---

## 1. Interior (manuscrito)

```
□ PDF exportado al tamaño exacto del trim (sin márgenes de papel extra)
□ Márgenes interiores correctos según número de páginas (ver tabla)
□ Tipografía embebida en el PDF
□ Capítulos siempre en página impar
□ Páginas preliminares completas:
    □ Portadilla
    □ Página de derechos (copyright + año + "Todos los derechos reservados")
    □ Tabla de contenidos con números de página correctos
□ Sin páginas en blanco no deseadas al final del documento
□ Imágenes en 300 DPI si las hay
□ Revisión ortográfica final pasada
□ Tamaño del archivo: menos de 650 MB
```

---

## 2. Portada

```
□ Archivo único: contratapa + lomo + tapa
□ Dimensiones verificadas con KDP Cover Calculator
□ Zona del ISBN vacía (mínimo 2" × 1,2" esquina inferior derecha contratapa)
□ Texto del lomo dentro de la zona segura (±0,0625" de tolerancia)
□ Sin texto ni elementos importantes en la zona de sangrado
□ Exportado como PDF impresión con marcas de sangrado
□ Resolución 300 DPI
□ Espacio de color RGB
□ Tamaño del archivo: menos de 650 MB
```

---

## 3. Datos en KDP

### Título y descripción
```
□ Título exactamente igual al de la portada (incluyendo subtítulo)
□ Descripción optimizada:
    □ 150–400 palabras
    □ Incluye keywords del nicho (PM, gestión de proyectos, IA, etc.)
    □ Primer párrafo habla del problema que resuelve (el lector lo ve sin expandir)
    □ Lista de beneficios con verbos de acción
    □ Sin "Este libro..." como primera frase
```

### Keywords y categorías
```
□ 7 palabras clave completadas
   Estrategia: buscar términos que usa el lector cuando busca soluciones, no el título del libro
   Evitar: el título del libro, el nombre del autor, "libro", "Amazon"
   
□ 2 categorías de Amazon elegidas
   Estrategia: una categoría más amplia + una más específica
   Para non-fiction PM: "Business & Money > Project Management" + subcategoría específica
```

### Precio
```
□ Precio definido según extensión:
   Guía corta (50–90 pág): USD 6,99 – 9,99
   Libro estándar (120–180 pág): USD 9,99 – 14,99
   Libro de autoridad (200+ pág): USD 14,99 – 19,99

□ Precio en USD (referencia para otros mercados, KDP convierte automáticamente)
```

### Distribución y derechos
```
□ KDP Select (exclusividad Amazon 90 días, acceso a Kindle Unlimited)
   O
□ Distribución ampliada (otros canales, sin exclusividad)

□ Territorios: "Worldwide rights — I own the copyright"
□ ISBN: KDP gratuito (suficiente para empezar) o propio si ya tenés
```

---

## 4. Antes de publicar

```
□ Vista previa del interior en el KDP Previewer (obligatorio)
   Verificar: márgenes, tipografía, páginas preliminares, imágenes
   
□ Vista previa de la portada completa en el previewer
   Verificar: lomo legible, contratapa sin cortes, zona ISBN libre

□ Precio de lista vs. precio mínimo de KDP (royalty 60% requiere precio ≥ USD 2,99)

□ ¿Publicar ahora o programar fecha de lanzamiento?
   Si tenés lista de lectores → programar con 7–14 días de anticipación para avisar
```

---

## 5. Post-publicación (primeras 72 horas)

```
□ Verificar que el libro aparece en Amazon (puede demorar 24–72 hs)
□ Pedir las primeras reseñas a lectores de confianza
□ Compartir en LinkedIn + canal YouTube
□ Verificar que las categorías asignadas son las correctas
□ Revisar la página del libro en Amazon: ¿la descripción se ve bien formateada?
```

## Referencia rápida de tiempos KDP

| Acción | Tiempo estimado |
|---|---|
| Revisión de interior | 24–72 hs |
| Revisión de portada | 24–72 hs |
| Libro disponible para compra | 24–72 hs tras aprobación |
| Cambios en precio | Pocas horas |
| Cambios en descripción/keywords | 24–48 hs |
| Reporte de ventas | Tiempo real en KDP dashboard |
| Cobro de regalías | 60 días después del mes de venta |
