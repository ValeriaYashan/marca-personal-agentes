# Vender en Amazon — Precio, Ads y Escala

## 1. ESTRATEGIA DE PRECIO EN EL TIEMPO

El precio no es fijo — es una herramienta de lanzamiento y escala.

### Fases de precio recomendadas

```
FASE 1 — Lanzamiento (primeros 7 días)
  Precio: USD 0,99 o USD 2,99
  Objetivo: acumular las primeras ventas y reseñas rápido
  Amazon pondera las ventas recientes para el ranking → precio bajo = más ventas = mejor ranking

FASE 2 — Consolidación (semana 2–4)
  Precio: subir gradualmente al 50–70% del precio final
  Objetivo: mantener el momentum sin frenar el volumen

FASE 3 — Precio definitivo (mes 2 en adelante)
  Precio final según extensión:
    Guía corta (50–90 pág):      USD 6,99 – 9,99
    Libro estándar (120–180 pág): USD 9,99 – 14,99
    Libro de autoridad (200+ pág): USD 14,99 – 19,99
```

### Kindle Countdown Deal (solo con KDP Select)
Promoción de precio programada directamente desde el dashboard de KDP:
```
- Duración: 1–7 días
- Precio mínimo: USD 0,99
- El royalty del 70% se mantiene aunque el precio sea < USD 2,99
- Amazon muestra el precio original tachado → señal visual de oferta
- Ideal para: relanzamientos, fechas especiales, impulsar un libro dormido
```

> Trigger: `"estrategia de precio para el lanzamiento"` → calcular fases con fechas concretas.

## 2. KDP SELECT — CUÁNDO SÍ, CUÁNDO NO

KDP Select = exclusividad con Amazon por períodos de 90 días.

### Cuándo conviene KDP Select ✅
- Primer libro: necesitás visibilidad y Kindle Unlimited da exposición
- Libro corto (< 100 páginas): el pago por páginas leídas puede superar el precio de venta
- Tenés audiencia en Amazon pero no en otras plataformas
- Querés usar Kindle Countdown Deals para promociones

### Cuándo NO conviene KDP Select ❌
- Tenés audiencia establecida en otras plataformas (Kobo, Apple Books, Google Play)
- Tu lector objetivo está fuera del ecosistema Amazon
- Querés vender en librerías físicas (requiere distribución ampliada sin KDP Select)
- Tenés varios libros y querés diversificar riesgos

### Cómo calcular si KU conviene
```
Pago por página leída (KENP): ~USD 0,004–0,005 por página
Libro de 150 páginas leído completo: 150 × 0,0045 = USD 0,675

Si el libro vale USD 9,99 → venta = USD 6,99 (royalty 70%)
Para igualar con KU → necesitás que cada lector lea el libro completo 10 veces 
→ No conviene KU para libros de más de USD 4,99
→ Sí conviene KU para guías cortas de USD 2,99 o menos
```

## 3. AMAZON ADS — PRIMERA CAMPAÑA

Amazon Ads es el sistema de publicidad dentro de Amazon. Para non-fiction en español es más barato y efectivo que Facebook o Instagram porque el lector ya está en modo compra.

### Tipos de campaña para empezar

**Sponsored Products (recomendado para empezar)**
Tu libro aparece en los resultados de búsqueda y en la página de otros libros similares.

### Configurar la primera campaña

```
1. Ir a KDP dashboard → Publicidad (Advertising)
2. Crear campaña → Sponsored Products
3. Configuración:
   □ Nombre: [Título libro] - Búsqueda automática
   □ Presupuesto diario: USD 3–5 (suficiente para empezar)
   □ Targeting: Automático (Amazon elige las keywords — ideal para primera campaña)
   □ Bid (oferta por clic): USD 0,25–0,40
   □ Duración: sin fecha de fin (pausar manualmente si no funciona)

4. Revisar a los 7 días:
   □ ACoS (Advertising Cost of Sales) < 40% = rentable
   □ ACoS > 70% = pausar y ajustar keywords
   □ Impresiones altas pero clics bajos → cambiar portada o título
   □ Clics altos pero ventas bajas → mejorar descripción
```

### Campaña Manual (después de 2–3 semanas de automática)
La campaña automática te dice qué keywords convierten → pasarlas a una campaña manual con bids más altos para esas keywords específicas.

```
Keywords de alto valor para non-fiction PM en español:
- "gestión de proyectos"
- "project management en español"
- "PMP libro"
- "metodologías ágiles libro"
- "administración de proyectos"
- "scrum libro"
```

> Trigger: `"armame la primera campaña de Amazon Ads"` → guiar paso a paso con configuración específica para el libro.

### Métricas clave
| Métrica | Qué significa | Objetivo |
|---|---|---|
| Impresiones | Cuántas veces se mostró el anuncio | > 1.000/semana |
| CTR (click rate) | % que hizo clic | > 0,3% |
| CPC | Costo por clic | < USD 0,50 |
| ACoS | % del ingreso gastado en ads | < 40% |
| ROAS | Ingreso por cada USD gastado | > 2,5× |

## 4. A+ CONTENT (CONTENIDO MEJORADO)

A+ Content permite agregar imágenes, tablas y módulos visuales a la página del libro en Amazon. Aumenta la conversión especialmente en mobile.

### Disponibilidad
- Disponible para libros con KDP Select o con Brand Registry
- Gratis dentro de KDP

### Módulos más efectivos para non-fiction
```
Módulo 1 — Banner de encabezado
  Imagen visual del libro + tagline principal

Módulo 2 — Tabla comparativa de capítulos
  "Qué aprenderás en cada capítulo" en formato tabla

Módulo 3 — Sobre la autora
  Foto + bio corta + credenciales visuales (badges PMP, MBA)

Módulo 4 — Para quién es este libro
  Columnas: "Este libro ES para vos si..." / "Este libro NO es para vos si..."
```

> Trigger: `"armame el A+ content para el libro"` → generar los textos de cada módulo listos para cargar.

## 5. CROSS-SELLING ENTRE LIBROS DE LA SERIE

Si publicás más de un libro, cada libro puede impulsar ventas de los siguientes.

### Dentro del libro
```
Último capítulo o página final:
"Si este libro te ayudó, el próximo de la serie es [Título].
En él vas a encontrar [promesa específica].
Encontralo en Amazon: [link corto o nombre exacto para buscar]"
```

### En la página de Amazon
- Amazon genera automáticamente secciones "También de esta autora" cuando tenés varios libros vinculados en Author Central
- Vincular todos los libros en Author Central → cada página muestra el catálogo completo

### Precio de bundle
KDP no permite bundles nativos de eBooks, pero podés:
- Crear un libro nuevo que sea la compilación de 2–3 libros cortos
- Precio del bundle: 70–80% del precio sumado de los individuales
- Descripción: "Incluye [Libro 1] + [Libro 2] + [Libro 3]"

> Trigger: `"cómo conecto los libros de la serie en Amazon"` → guiar la configuración en Author Central + texto de cross-selling para incluir en cada libro.

## 6. KDP REPORTS — CÓMO LEER LOS DATOS

KDP dashboard → Reports. Los datos que importan y qué hacer con cada uno:

| Métrica | Dónde verla | Qué significa | Cuándo actuar |
|---|---|---|---|
| **Units Ordered** | Sales Dashboard | Ventas por día/mes | Si baja sostenido → revisar precio o ads |
| **KENP Read** | KDP Select | Páginas leídas en Kindle Unlimited | Si es alto → el libro engancha; si es bajo → problema de retención |
| **BSR** (Best Seller Rank) | Página del libro en Amazon | Ranking general y por categoría | BSR < 10.000 = ventas activas; > 100.000 = casi sin ventas |
| **Royalties** | Payment Report | Ingresos reales | Comparar con ACoS de Ads para ver rentabilidad neta |
| **Free Units** | Si hiciste promo gratuita | Descargas gratis | Alto = buena portada/descripción; conversión a ventas = buen libro |

### Lectura semanal recomendada (5 minutos)
```
Lunes:
  □ Ventas de la semana anterior vs. semana previa → tendencia
  □ KENP si estás en KDP Select → retención del libro
  □ ACoS de Ads → rentabilidad de la publicidad
  □ BSR actual en categorías principales → posición

Si ventas caen > 30% semana a semana:
  → Revisar precio (¿subiste mucho?)
  → Revisar Ads (¿se agotó el presupuesto?)
  → Ver si hay reseñas negativas nuevas
```

### Workflow con Google Drive MCP (recomendado)

Google Drive MCP está conectado — esto permite análisis automático sin copiar datos manualmente.

**Setup inicial (una sola vez):**
```
1. En KDP → Reports → Prior Months' Royalties → Download (.csv)
2. En Google Drive → crear carpeta "KDP Reports"
3. Subir el CSV ahí
```

**Cada semana (2 minutos):**
```
1. Descargar nuevo CSV desde KDP Reports
2. Subirlo a la carpeta "KDP Reports" en Drive
3. Decirle a Claude: "leé el último reporte de KDP que subí a Drive y analizá las ventas"
```

Claude lee el CSV directamente desde Drive y entrega:
- Tendencia de ventas semana a semana
- Rentabilidad real (ventas - ACoS de Ads)
- Comparación entre marketplaces (amazon.com vs amazon.es vs amazon.com.mx)
- Diagnóstico + 1 acción concreta recomendada

> Trigger: `"cómo van las ventas del libro"` → si hay CSV en Drive, Claude lo lee directamente; si no, guía la lectura manual del dashboard.

## 7. AUDIOLIBRO — ACX / AUDIBLE

Extensión natural del libro una vez publicado. El mercado de audiolibros crece 25% anual.

### Opciones para producir el audiolibro
```
Opción A — Voz propia (recomendado para non-fiction con voz autoral fuerte)
  + Auténtico, íntimo, refuerza la marca personal
  + Sin costo de producción salvo equipo
  - Requiere tiempo de grabación (~2 hs por hora de audio)
  - Necesita espacio silencioso y micrófono básico (USD 50–100)

Opción B — Narrador profesional vía ACX
  + Calidad profesional
  + Sin tiempo de grabación propio
  - Costo: porcentaje de regalías (50% por 7 años) o pago único (USD 200–400 por hora)
  
Opción C — IA de voz (ElevenLabs, Murf.ai)
  + Rápido y económico
  + Calidad aceptable para non-fiction técnico
  - ACX/Audible todavía tiene política en revisión sobre voz IA — verificar antes de subir
```

### Publicar en ACX
```
1. Ir a acx.com → crear cuenta con el mismo email de KDP
2. Agregar el libro (buscar por ISBN o título)
3. Elegir: subir audio propio o buscar narrador
4. Formato requerido:
   □ MP3 a 192 kbps o WAV a 44.1 kHz
   □ Volumen RMS entre -23 y -18 dBFS
   □ Silencio al inicio y al final de cada archivo
   □ Un archivo por capítulo + archivo de apertura
5. Distribución: Audible + Amazon + iTunes automáticamente
```

> Trigger: `"quiero hacer el audiolibro de [título]"` → guiar la decisión de producción + proceso de subida.

## 8. TRADUCCIÓN AL INGLÉS

El mercado PM en inglés en Amazon es 20× más grande. Una vez que el libro en español funciona, la traducción es el paso de mayor leverage.

### Cuándo conviene traducir
```
✅ Conviene cuando:
  - El libro en español tiene > 20 reseñas y BSR estable
  - El tema tiene demanda probada en inglés (verificar con Amazon keyword tools)
  - Tenés tiempo o presupuesto para revisión de la traducción

❌ No conviene todavía si:
  - El libro en español tiene < 10 reseñas
  - El contenido es muy local (ejemplos solo argentinos sin adaptación)
  - No podés revisar o validar la calidad de la traducción
```

### Proceso de traducción con IA
```
PASO 1 — Traducción base con IA
  Herramienta: DeepL (mejor que Google Translate para textos técnicos)
  o Claude: "traducí este capítulo al inglés manteniendo el tono directo y práctico"

PASO 2 — Revisión de terminología PM
  Los términos técnicos tienen variantes en inglés (sponsor vs. project sponsor,
  backlog vs. product backlog) → verificar consistencia con el estándar PMBOK en inglés

PASO 3 — Revisión de ejemplos
  Adaptar ejemplos muy locales: "en Argentina" → "in Latin America" o ejemplo nuevo
  Los casos de YPF, Garantizar, CAMMESA son válidos en inglés con contexto breve

PASO 4 — Revisión nativa (recomendado)
  Plataforma: Reedsy, Upwork
  Costo estimado: USD 0,05–0,10 por palabra para revisión (no traducción)
  Para libro de 20.000 palabras: USD 1.000–2.000

PASO 5 — Nuevo título, portada y descripción para el mercado anglófono
  → Activar portadas-amazon con instrucción "para mercado en inglés"
  → Nueva descripción HTML en inglés con keywords del mercado US/UK
```

> Trigger: `"evalúo traducir el libro al inglés"` → diagnóstico de conveniencia + plan de acción.
